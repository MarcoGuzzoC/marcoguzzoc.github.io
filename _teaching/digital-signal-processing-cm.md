This class is an introduction to digital filtering using *Linear Time Invariant* (LTI) filters. The focus is solely on real, causal filters. It follows an introduction class on digitalization (quantization and sampling) and draws a connection between digital and analog filtering.  

**Topics:** Digital signals, Discrete Fourier Transform, digital filtering using LTI, filter classification (FIR, RIF), Z-transform, Zero/Pole representation, stability criterion, bilinear transformation.

**Level:** L2 students.

**Teaching load:** 20 hours.
